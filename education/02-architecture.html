Runnable 2.0 · Frontend Guide

app/ 패키지 역할

Cesium 기반 러닝 경로 제작 서비스의 프론트엔드입니다. Nuxt 모노리포 안에서 FSD(Feature-Sliced Design) 변형을 따라, 상위 레이어가 하위 레이어만 의존하는 단방향 구조로 정리되어 있습니다.

Nuxt 4 Vue 3 · Composition API Cesium FSD 5-layer entities 6 · features 11
01 / DEPENDENCY FLOW

레이어와 의존 방향

import 은 항상 위에서 아래로만 흐릅니다. 역방향 import 와 feature 간 교차 의존은 금지이며, 기능 조합이 필요하면 widget facade 계층에서 묶습니다.

pages 라우팅 진입점. 최상위 widget facade 만 호출하는 얇은 화면 조합 (index · settings · admin · share)
widgets 화면 단위 레이아웃 + Facade. 여러 feature·entity 를 단일 인터페이스로 묶음 (map-shell, facility-overlay)
features 사용자 기능 단위. 경로 그리기·탐색·비교 등 동작 UI + 로직
entities 도메인 단위. route · user · boundary 등 데이터·표시 객체. shared 만 의존
shared 공용 UI · 유틸 · 지도 런타임. 외부 라이브러리만 의존하는 자체 완결 레이어

pages → widgets → features → entities → shared → external libs

02 / DIRECTORIES

app/ 디렉터리 역할

FSD 5개 레이어와, 그 위에서 동작하는 Nuxt·플러그인 인프라 디렉터리입니다.

pages app/pages/

Nuxt 파일 라우팅. 화면을 조합만 하고 로직은 widget facade 에 위임합니다.

index.vuesettings.vue admin/share/[routeId]

widgets app/widgets/

화면 단위 레이아웃 + Facade. map-shell 이 인증·레이어·그리기·저장 등 11개 sub-facade 를 조합합니다.

map-shellfacility-overlay use*Facade.ts

features app/features/

사용자 기능 11종. 각 기능은 api·lib·model·ui 세그먼트 중 필요한 것만 둡니다.

draw-routeexplore route-comparecamera+7

entities app/entities/

도메인 단위 6종. 데이터·표시 객체와 도메인별 sideeffect·store 를 보유합니다.

routeuserboundary facilitygradientnotification

shared app/shared/

공용 UI primitive, composable 유틸, Cesium 지도 런타임(useCesiumRuntime 등). 자체 완결.

ui/lib/ lib/map/model/

plugins-ext app/plugins-ext/

런타임 플러그인 슬롯 시스템. PluginManifest 로 chip·sidepanel·dashboard·popup 슬롯을 정적 등록합니다.

registry.tstypes.ts chip/sidepanel/dashboard/popup

assets app/assets/

CSS 토큰(primitive·semantic)과 컴포넌트·페이지 스타일, 아이콘 자산.

css/basecss/componentsicons

plugins · middleware app/

Nuxt 런타임 훅. developer-gate 플러그인, admin-only 전역 미들웨어, 루트 app.vue · app.config.ts(z-index 티어).

developer-gateadmin-only.global app.config.ts
03 / SLICE SEGMENTS

슬라이스 내부 4세그먼트

entities·features 의 각 슬라이스는 아래 세그먼트로 책임을 나눕니다. 필요한 세그먼트만 둡니다 — 예) entities/route 는 lib·model·ui 만, entities/notification 은 lib·model 만.

api/
use*Sideeffect.ts

외부 API 호출 + store 동기화. 결과를 store 로 흘려보내는 단방향 흐름.

model/
use*Store.ts · use*Action.ts

useState 기반 상태 store 와 액션. 도메인 상태의 단일 출처.

lib/
도메인별 함수

순수 비즈니스 로직 — 계산·변환·파싱·렌더러. 부수 효과 없음.

ui/
<Name>.vue

도메인·기능 컴포넌트 (popup · panel · modal · toggle).

04 / INVENTORY

entities · features 목록

현재 도메인 6종과 기능 11종의 역할입니다.

entities — 도메인 (6)

  • route러닝 경로 데이터·표시 객체
  • user사용자·인증 도메인
  • boundary행정구역 경계(시·구·동)
  • facility시설물 POI(Billboard 핀)
  • gradient경사도·고도 그라디언트
  • notification알림 표시

features — 기능 (11)

  • base-map기본 지도 레이어
  • camera카메라 시점 제어
  • draw-route경로 그리기·분할
  • elevation-layer고도 레이어
  • explore경로 탐색·둘러보기
  • graphic-quality그래픽 품질 설정

features (계속)

  • route-compare경로 비교
  • route-info경로 정보 표시
  • route-social경로 공유·소셜
  • share-viewer공유 링크 뷰어
  • view-mode보기 모드 전환
